1. Overview & Scope

This document provides a consolidated reference of admin-level controls for the four most common AI assistant tools deployed in enterprise environments. These are settings configured by IT teams through admin consoles, MDM systems, and APIs — not end-user preferences.

8. Implementation Priority

Phase 1: Identity & Access (Highest Priority)

  • Deploy SSO across all four tools
  • Enable SCIM where available for automated provisioning
  • Verify domains and restrict external invites
  • Configure MFA (native or via IdP)

Phase 2: Data Governance

  • Verify training opt-out on all tools
  • Set retention policies aligned with data classification
  • Configure DLP rules (especially Gemini native DLP)
  • Select data residency regions where available

Phase 3: Feature Governance

  • Audit enabled features per tool — disable unused high-risk features
  • Configure RBAC roles (ChatGPT) and managed settings (Claude)
  • Set extension/MCP allowlists (Cursor, Claude)
  • Establish spending limits (Cursor, ChatGPT, Claude)
  • Configure workspace agents governance and approval gates (ChatGPT)
  • Review ChatGPT Sites and Codex plugin policies
  • Enable sandbox enforcement for Claude Code and Cursor agents
  • Review AI Control Center security modules (Gemini)

Phase 4: Monitoring & Compliance

  • Enable audit logs on all tools and route to SIEM
  • Set up usage analytics dashboards
  • Configure Compliance APIs (Claude, ChatGPT) for automated monitoring
  • Set up billing groups for cost attribution (Cursor)
  • Enable AI code tracking and Cursor Blame (Cursor Enterprise)
  • Configure alerts for anomalous usage patterns
  • Review AI Control Center usage reports (Gemini)
  • Document controls for compliance frameworks (SOC 2, ISO 27001)
